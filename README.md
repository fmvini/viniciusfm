# Portfólio de Vinícius F. Marrocos

Portfólio pessoal em React, TypeScript e Vite. Apresenta projetos, stack, formação e contato.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite. Para validar a versão de produção, use `npm run build`. Os testes de navegador rodam com `npm run test:e2e` após instalar o Chromium do Playwright.

## Identidade visual

A direção Lima, escolhida entre três propostas verdes, usa fundo quase preto, tipografia forte, acento verde-lima, retrato pessoal e capturas reais dos projetos. Há temas escuro e claro.

## Conteúdo e imagens

Textos e links pessoais ficam em `src/content.ts`. A foto e os prints dos dashboards em `public/images/` foram fornecidos pelo proprietário do portfólio. Os ícones dos projetos foram obtidos dos próprios aplicativos. A fonte Geist tem sua licença em `public/fonts/OFL.txt`.
